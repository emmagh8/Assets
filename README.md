# Basics & Prerequisites

> Before diving into SOC work, you need a solid foundation in networking, operating systems, and how the internet works.

---

## Networking Fundamentals

- [Professor Messer — CompTIA Network+ Course](https://www.professormesser.com/network-plus/n10-008/n10-008-video/n10-008-training-course/) — Free and thorough
- [TryHackMe — Pre-Security Path](https://tryhackme.com/path/outline/presecurity) — Covers networking basics interactively
- [Cisco Networking Basics (free)](https://skillsforall.com/course/networking-basics) — Good intro to TCP/IP, DNS, DHCP
- [IP Addressing & Subnetting by David Bombal](https://www.youtube.com/watch?v=E-J8EPUvc8E)

**Key concepts to understand:**
- TCP/IP, UDP
- DNS, DHCP, HTTP/S
- IP addressing & subnetting
- OSI model (all 7 layers)
- Firewalls, proxies, NAT

## Linux Fundamentals

- [TryHackMe — Linux Fundamentals (Part 1, 2, 3)](https://tryhackme.com/module/linux-fundamentals)
- [OverTheWire: Bandit](https://overthewire.org/wargames/bandit/) — Learn Linux by playing
- [Linux Command Line Basics — freeCodeCamp](https://www.youtube.com/watch?v=ZtqBQ68cfJc)

**Key skills:**
- File system navigation
- File permissions & users
- Processes & services
- Basic bash scripting
- Log file locations (`/var/log/`)
